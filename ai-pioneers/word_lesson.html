1️⃣ ما هو Word ومميزاته؟

Word هو برنامج لمعالجة النصوص من إنتاج شركة Microsoft، يُستخدم لكتابة وتنسيق ومراجعة النصوص وإدراج الصور والجداول والأشكال، ثم طباعة المستند أو مشاركته إلكترونيًا.

2️⃣ فتح البرنامج وشاشته الافتتاحية

يُفتح البرنامج من قائمة Start ← Productivity ← Word، ثم يُختار Blank Document من تبويب File لإنشاء مستند جديد.

4️⃣ حفظ المستندات وصيغ الملفات

من تبويب File ← أمر Save أو Save As أو بالمفاتيح Ctrl+S.

عند التعامل مع مستند جديد لم يُحفظ بعد: لا فرق بين Save وSave As — كلاهما يفتح مربع حفظ باسم. أما مع مستند محفوظ مسبقًا: Save يحفظ بنفس الاسم والمكان، وSave As يحفظه بنسخة جديدة أو مكان مختلف.

6️⃣ تنسيق الحروف والفقرات

تنسيق الحروف (Font) من تبويب Home: نوع الخط، الحجم، اللون، التسطير، المائل، الغامق، التكبير/التصغير، الكتابة المرتفعة (X²) والمنخفضة (CH₂).

تنسيق الفقرات (Paragraph) من تبويب Home: المحاذاة، التباعد بين الأسطر، خلفية الفقرة، التعداد النقطي والرقمي، زيادة/إنقاص المسافة البادئة، اتجاه الفقرة، الفرز وترتيب البيانات.

8️⃣ عمليات الطباعة

قبل الطباعة تأكد من: تعريف الطابعة، توصيل كابل البيانات (Data) وكابل الكهرباء (Power)، وجود ورق بالطابعة، وتشغيلها.

فتح الملف: File ← Open، ثم إعطاء أمر الطباعة: File ← Print أو Ctrl+P.
